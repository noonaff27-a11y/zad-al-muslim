# زاد المسلم | قصص الأنبياء للأطفال — نسخة تفاعلية

- واجهة مكتبة بالكوفرات.
- كل قصة بعدد صفحات مختلف حسب أحداثها.
- كل صفحة فيها رسمة تعبر عن المحتوى + نص.
- لا يوجد تجسيد لله أو الملائكة أو الأنبياء في الرسومات.
- قسم تلوين.
- قسم أنشطة.
- اختبار عشوائي.
- رسالة الإجابة الصحيحة: «أحسنت بارك الله فيك».
- رسالة الإجابة الخاطئة: «أعد قراءة القصة».
- عداد زيارات محلي.
- لوحة متفوقين محلية.
- لإطلاق عداد/ترتيب عالمي حقيقي يجب ربط الموقع بقاعدة بيانات مثل Supabase/Firebase.
- ارفع المجلد إلى GitHub Pages كما هو.
